### 🔦 Featured Projects

#### 🖥️ [Online labs](https://github.com/4rthur-Root/Online-Labs) - *Online* platforms hands-on
A curated collection of my training on different SOC platforms, CTFs, and certifications. Everything is documented with a clear README and shows how I approach every topic.

`Forensic` `Hack The Box` `TryHackMe` `CyberDefenders`

#### 🛰️ [NYX](https://github.com/4rthur-Root/NYX) - SIEM Correlation Engine + SOAR
Python-based SIEM correlation engine with automated SOAR response: stateful multi-source log analysis, YAML-defined detection rules, YARA integration, and a Grafana dashboard for real-time visibility.

`Python` `Detection Engineering` `SOAR` `YARA` `Grafana`

#### 🛡️ [DevSecOps Web Lab](https://github.com/4rthur-Root/DevSecOps-web-lab) - Secured Web Stack + Kill Chain Simulation
Automated deployment of a hardened web stack using Terraform and Ansible: Nginx/ModSecurity WAF with 846 OWASP CRS rules in front of OWASP Juice Shop, hardened MySQL, centralized SOC monitoring with Grafana/Loki, and a realistic red-to-blue attack simulation workflow.

`Terraform` `Ansible` `ModSecurity` `Grafana/Loki` `OWASP Top 10`

#### 🖥️ [Cyber Lab](https://github.com/4rthur-Root/CyberLab) - VM Lab Orchestrator *(team project)*
Java desktop application that manages VirtualBox-based lab environments for security analysts: groups VMs by lab, drives them through `VBoxManage`, timestamps analyst notes per VM, and exports structured PDF reports for lab outcomes and investigations.

`Java 17` `SQLite` `VBoxManage` `Design Patterns`
